# comp163-assignment-4

&nbsp;College Life Adventure COMP 163  Assignment 4



Overview

Text-based game about college decisions: course load, study focus, and semester outcome.



Concepts Used

\- Comparison operators: course-load decision

\- if / elif / else branching: all decisions

\- Membership operators: validates study focus 

\- Logical operators (and, or, not): combined conditions 

\- Identity operators (is, is not): type checks before endings 

\- Nested if statements: 2+ levels in final assessment

\- Multiple endings: at least 3 based on stats
